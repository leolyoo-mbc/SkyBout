## User Scenarios & Testing *(mandatory)*

높이 유지 시험에서 ‘무입력’은 WASD 무입력을 뜻하며 Space는 계속 누른다. 독립 수학/충돌 fixture는 목표0을 명시해 원점 좌표계로 검증할 수 있으나 실제 게임의 기본 목표와 실제 씬 인수 시험은2m다.

### User Story 1 - 낮거나 높은 위치에서 목표 높이로 합류하기 (Priority: P1)

플레이어는 공중에서 새 스페이스바를 누르고 유지하면 별도 높이 조작 없이 발 높이2m로 올라가거나 내려간다. 떼면 즉시 접히고 높이 보정 없이 중력으로 낙하하며 다시 누르면 재전개할 수 있다. 전개/접기 순간 위치나 속도가 튀어서는 안 된다.

**Why this priority**: 낮으면 상승하고 높으면 하강하여 자연스럽게 높이를 맞추는 것이 이번 단계의 핵심이다.

**Independent Test**: 섬과 겹치지 않는 허공에서 낙사 경계보다 높은 목표 아래·위·동일 높이에 각각 전개하고, 이동 입력 없이 목표로 수렴하여 유지되는지 관찰한다.

**Acceptance Scenarios**:

1. **Given** 목표보다 낮지만 낙사 경계 아래로 내려가지 않은 생존 공중 플레이어, **When** 새 스페이스바 입력으로 글라이더를 펼치면, **Then** 전개 위치에서 연속적으로 움직여 목표 쪽으로 상승하고 도달할수록 수직 이동이 잦아든다.
2. **Given** 목표보다 높은 생존 공중 플레이어, **When** 글라이더를 펼치면, **Then** 목표 쪽으로 하강하고 목표 부근에서 감속해 멈추며 일정 하강을 계속하지 않는다.
3. **Given** 목표 높이에서 수직 움직임 없이 글라이딩을 시작하는 플레이어, **When** 이동 키를 누르지 않으면, **Then** 불필요한 상승·하강 없이 그 높이를 유지한다.
4. **Given** 상승 또는 빠른 하강 중인 생존 공중 플레이어, **When** 전개하면, **Then** 위치가 순간 변경되지 않고 수직 속도가 부드럽게 목표 접근 움직임으로 바뀐다. 기존 진행 방향 때문에 일시적으로 목표에서 멀어질 수 있지만 이후 수렴한다.
5. **Given** 목표 높이에 도달한 글라이더 플레이어, **When** 새 입력 없이 10초간 기다리면, **Then** 목표 허용 오차 안에서 안정적으로 머물며 반복 상승·하강이나 지속적인 높이 이탈이 발생하지 않는다.
6. **Given** Space를 유지하여 비행 중인 플레이어, **When** Space만 해제하면, **Then** 날개·전개·높이 보정을 종료하고 현재 수직 속도를 유지한 채 중력 낙하로 바뀐다. WASD 조작은 유지되며 새 공중 Space로 재전개한다. 물리 처리 전에 해제된 짧은 공중 탭은 전개를 예약하지 않는다.

### User Story 2 - 높이를 맞추면서 기존 방향 조작과 착지 유지하기 (Priority: P1)

플레이어는 높이가 자동으로 맞춰지는 중에도 WASD로 이동하며, 실제 섬 표면에 착지하면 글라이더를 닫고 기존 지상 조작으로 돌아간다.

**Why this priority**: 자동 높이 보정이 기존 이동과 착지를 방해하면 글라이딩을 실제 플레이에 사용할 수 없다.

**Independent Test**: 목표 아래·위에서 8방향 이동, 방향 전환, 입력 해제를 수행하고, 하강 경로의 섬 표면에 착지한 뒤 다시 점프한다.

**Acceptance Scenarios**:

1. **Given** 목표로 상승·하강하거나 목표에 머무는 글라이더 플레이어, **When** WASD로 이동하거나 방향을 바꾸면, **Then** 기존 화면 기준 방향·수평 최고 속도·가속·감속·대각선 제한이 유지되고 높이 보정도 계속된다.
2. **Given** 글라이딩 중 이동하는 플레이어, **When** 모든 이동 키를 놓으면, **Then** 기존 규칙으로 수평 이동은 감속하여 멈추되 높이 보정과 도달 후 높이 유지는 계속된다.
3. **Given** 하강 중 실제 걸을 수 있는 표면에 발이 닿는 글라이더 플레이어, **When** 착지가 판정되면, **Then** 목표 높이 도달 전이라도 글라이더와 보정을 종료하고 지상 이동 및 새 스페이스바 점프를 허용한다.
4. **Given** 섬 옆면 또는 상승 경로의 장애물에 접촉한 플레이어, **When** 목표까지의 경로가 막히면, **Then** 장애물을 통과하거나 목표로 순간 이동하지 않는다. 옆면 접촉만으로 착지하지 않으며, 경로가 다시 열리면 보정을 계속한다.

### User Story 3 - 탈락·재시작 후에도 일관된 높이 보정 사용하기 (Priority: P2)

플레이어는 낙사 규칙을 그대로 따르며 재시작 후 이전 비행의 수직 움직임 없이 다시 점프하고 글라이더를 펼칠 수 있다.

**Why this priority**: 목표 높이 보정이 탈락을 무효화하거나 다음 시도에 남아서는 안 된다.

**Independent Test**: 낙사 경계 위·동일·아래에서 전개를 시도하고, 탈락과 R 재시작을 반복한 뒤 지상·비전개 공중 상태 및 새 글라이딩을 확인한다.

**Acceptance Scenarios**:

1. **Given** 발 위치가 낙사 경계보다 낮은 플레이어, **When** 전개 또는 높이 보정과 탈락 판정이 겹치면, **Then** 탈락이 우선하고 보정으로 구제되지 않으며 기존 탈락 안내가 표시된다.
2. **Given** 목표보다 낮지만 낙사 경계와 같거나 높은 생존 공중 플레이어, **When** 유효하게 전개하면, **Then** 경계와 같다는 이유만으로 탈락하지 않고 상승 보정을 시작한다. 이후 실제로 경계 아래로 진입하면 탈락한다.
3. **Given** 글라이딩 후 탈락한 플레이어, **When** 새 R 입력으로 재시작하면, **Then** 기존 시작 위치·방향으로 복귀하고 글라이더 및 이전 보정 움직임이 남지 않는다. 새 점프와 새 공중 전개가 가능하며 유지 중이던 스페이스바로 자동 실행되지 않는다.
4. **Given** 생존 글라이더 플레이어, **When** 초점을 잃거나 비활성화하면, **Then** 유지 입력을 취소하여 전개/높이 보정을 종료하고 중력을 복원한다. 복귀만으로 자동 재전개하지 않으며 키 해제 후 새 공중 누름으로 같은 목표를 사용한다. 전체 Player 비활성 중에는 몸체 물리도 진행되지 않는다.

### Edge Cases

- 목표와 같은 높이에서 수직 속도가 있으면 순간 정지시키지 않고 감속하여 허용 오차 안으로 복귀한다.
- 목표 부근의 작은 높이 차이가 반복 방향 전환이나 눈에 띄는 떨림을 일으키지 않는다.
- 목표는 전개한 높이·수평 위치·발아래 지형이 바뀌어도 달라지지 않는다. 지형을 따라가는 비행은 이번 범위가 아니다.
- 빠른 하강 중 전개해도 감속 과정에서 낙사 경계 아래로 내려가면 기존 규칙대로 탈락한다. 생존을 보장하는 순간 상승은 제공하지 않는다.
- 충돌로 목표 도달이 불가능한 동안에는 수렴 시간 기준을 적용하지 않지만 충돌·착지·낙사 규칙은 계속 적용한다.
- 목표 높이에 머물러 낙사하지 않는 것은 정상이다. 기존의 ‘글라이딩하면 결국 낙사’ 시험은 강제로 경계 아래에 진입하는 조건으로 구분한다.
- Space 유지 중에는 목표 재설정·추가 점프·재전개를 반복하지 않는다. 실제 해제는 접기이며, 해제 후 새 공중 누름은 재전개다. 지상 점프 키 유지가 자동 공중 전개를 만들지는 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 글라이딩에는 모든 전개에 공통인 사전 설정 목표 발 월드Y=2m가 있어야 한다. 현재 섬 표면Y=0에서 기본 점프 높이2m와 같다. 현재 높이와 목표는 동일한 발 위치 기준이며 전개 위치나 지형에서 새 목표를 캡처하지 않는다. 점프 설정을 런타임에 바꿀 때 목표까지 자동 변경하는 기능은 이번 요청에 포함하지 않는다.
- **FR-002**: 생존 글라이딩 상태에서 목표보다 낮으면 상승하고 높으면 하강하여 목표에 접근해야 한다. 이전 수직 움직임의 감속 구간을 제외하면 목표와의 차이를 줄여야 하며 목표 도달 후에는 허용 오차 안에서 유지해야 한다.
- **FR-003**: 전개 및 보정 중 위치 순간 변경과 수직 속도 순간 전환을 일으키지 않아야 한다. 목표에 접근하면서 감속해야 하며 반복적인 목표 통과나 높이 떨림 없이 안정되어야 한다. 검증 범위와 허용치는 SC-001~SC-003을 따른다.
- **FR-004**: 보정은 이동 입력 유무와 관계없이 유효한 Space를 유지하여 전개 중일 때만 적용해야 한다. Space 해제 시 날개·전개·대기 중 전개 요청을 취소하고 중력을 복원하되 위치/수직 속도를 스냅하지 않는다. 지상·비전개 공중·탈락 상태에는 보정을 적용하지 않는다.
- **FR-005**: 기존 화면 기준 WASD 수평 조작, 최고 속도, 가속·감속, 방향 전환, 대각선 속도 제한과 입력 해제 후 정지를 유지해야 한다. 높이 보정을 위해 자동 전진이나 새 조작 키를 요구하지 않아야 한다.
- **FR-006**: 지상 새 입력은 점프이며 키 유지로 자동 전개하지 않는다. 새 공중 누름은 전개하고 해제는 접기, 해제 후 새 공중 누름은 재전개다. 키 유지 중 중복 처리는 금지하며 재전개해도 동일 목표를 사용한다. 짧은 지상 탭의 점프 요청은 보존하지만 해제된 공중 전개 요청은 보존하지 않는다.
- **FR-007**: 실제 걸을 수 있는 표면으로 하강 착지하면 보정과 전개를 종료하고 기존 지상 조작을 복원해야 한다. 목표가 표면과 다르더라도 착지가 우선하며, 옆면 접촉은 착지로 취급하지 않아야 한다. 보정 때문에 장애물을 관통해서는 안 된다.
- **FR-008**: 발 위치가 기존 낙사 경계보다 엄격히 낮으면 보정보다 탈락을 우선해야 한다. 경계와 같은 높이는 그 이유만으로 탈락하지 않아야 하며, 이미 탈락한 플레이어를 전개나 보정으로 되살려서는 안 된다.
- **FR-009**: 탈락·R 재시작 시 글라이더와 이전 보정 움직임을 정리해야 한다. 최초 시작 위치·방향 및 기존 입력 해제 정책을 보존하고, 새 전개는 과거 비행의 움직임 없이 동일 목표를 사용해야 한다.
- **FR-010**: 초점 상실·비활성화 시 미처리 입력과 유지 입력을 정리하고 전개를 종료해야 한다. 복귀만으로 추가 점프·전개·목표 재설정이 발생하지 않아야 하며 해제 후 새 입력에만 재전개를 허용한다. 기존 수평 입력 해제 정책은 보존한다.
- **FR-011**: 현재 디렉터리의 기존 게임을 확장해야 한다. 기존 섬 하나·로컬 플레이어 한 명으로 검증 가능해야 하며, 명시적으로 교체한 글라이딩 수직 이동 외의 점프·추락·낙사·재시작·카메라 동작을 보존해야 한다.

### Key Entities *(include if feature involves data)*

- **목표 비행 높이**: 모든 글라이딩 시도에 공통으로 적용하는 사전 설정 발 위치 높이. 낙사 경계보다 높고 기존 시험 공간에서 접근 가능한 값을 사용한다.
- **높이 보정 상태**: 현재 높이와 목표의 차이 및 현재 수직 움직임에 따라 상승·하강·감속·유지를 나타내는 비행 상태. 글라이딩 종료 시 잔류하지 않는다.
- **목표 허용 오차**: 도달 및 안정적 유지 여부를 판정하는 높이 범위. 이번 검수 기본값은 목표의 위아래 각각 0.1m다.
- **지지 표면과 낙사 경계**: 높이 보정과 별개로 착지 및 탈락을 결정하는 기존 기준이다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 장애물 없이 낙사 경계에서 충분히 떨어진 공간에서 목표 대비 -3m·-1m·0m·+1m·+3m, 초기 수직 정지 조건을 각각 5회 시험한다. 25회 모두 전개 후 5초 안에 목표 ±0.1m에 도달하고 이후 10초간 그 범위를 유지한다. 목표 높이 정지 조건에서는 처음부터 해당 범위를 유지한다.
- **SC-002**: 목표 아래·위에서 각각 초기 수직 속도 +5m/s와 -5m/s로 전개하는 네 조건을 각 5회 시험한다. 충돌과 낙사 없이 감속할 공간을 확보한 20회 모두 5초 안에 목표 ±0.1m에 도달하고 이후 10초간 유지한다. 전개 직전·직후 위치와 수직 속도가 연속적이며, 전개 및 접근 중 0.1초 구간의 수직 속도 변화는 1m/s를 넘지 않는다.
- **SC-003**: SC-001~SC-002의 모든 시험에서 목표를 반대편으로 0.1m 넘게 지나치는 횟수는 각 시험당 최대 1회이며, 안정 구간의 높이 최대·최소 차이는 0.1m 이하다. 플레이 관찰에서 위치 도약·반복 출렁임 없이 감속해 머무는 것을 확인하고 관찰 결과를 별도 기록한다.
- **SC-004**: 목표 아래·위·도달 상태에서 각각 8방향 이동, 방향 전환, 입력 해제를 시험하여 기존 수평 조작 기준을 100% 유지하고 모든 조건에서 높이 보정도 계속된다. 이동 해제 후 자동 전진과 반복 스페이스바에 의한 목표 변경은 0회다.
- **SC-005**: 하강 착지·옆면 접촉·상승 경로 차단을 각각 5회 시험하여 15회 모두 지정된 착지·충돌 기준을 충족한다. 지형 관통과 목표로의 순간 이동은 0회이며 착지 후 새 지상 점프가 가능하다.
- **SC-006**: 낙사 경계 위·동일·아래의 판정과 아래 진입·전개 겹침을 각각 5회 시험하여 기존 탈락 기준을 100% 유지한다. `전개 → 경계 아래 진입 → 탈락 → R 재시작 → 새 점프·전개`를 10회 반복하여 보정 잔류·자동 입력 실행은 0회다.
- **SC-007**: 초점 전환 및 컴포넌트/전체 Player 비활성화·재활성화를 각각5회 시험하여 전개 종료·중력 복원·유지 키 자동 재전개 없음·해제 후 새 입력 재전개를 확인한다. 비전개 이동·점프·추락·재시작·카메라의 변경되지 않은 기준을100% 유지한다. 실제 검증과 미검증을 분리한다.
- **SC-008**: 공중 Space 유지→Space만 해제→WASD 유지하며 낙하→새 Space 재전개를5회 시험해 해제 후 첫 물리 갱신까지 전개/날개가 모두 꺼지고 중력이 복원되어야 한다. 전개 전 해제된 탭은 전개하지 않는다. 실제 SampleScene에서는 누른 동안 발Y=2±0.1m를10초 유지하고 해제 후 자연 낙사/R 복귀를10회 수행한다.

## Assumptions

- 범위는 사용자 로드맵의 6단계이며 현재 디렉터리의 프로젝트를 이어서 진행한다. 이번 산출물은 명세이며 런타임 구현이나 플레이 검증 완료를 의미하지 않는다.
- ‘정해진 비행 높이’는 전개 위치나 지면과의 거리가 아닌 공통 발 월드Y=2m다. 사용자가 지정한 값이며 현재 기본 점프 높이와 같다.
- 목표는 실행 중 플레이어가 변경하지 않는다. Space 해제 접기는 포함하며 별도 접기 키, 목표 UI, 지형 추종, 여러 고도, 연료/시간 제한은 제외한다.
- 목표 ±0.1m, 5초 수렴, 10초 유지 및 속도 변화 한도는 ‘자연스럽게’의 초기 검수 기준으로 채택한 기본값이다. 수렴 시험의 거리·초기 속도 범위는 SC-001~SC-002로 한정하며 장애물 및 낙사가 우선한다.
- `specs/006-deploy-glider/spec.md`까지를 선행 기준으로 삼는다. 이전의 ‘일정한 하강·목표 상승 및 유지 금지’는 5단계 범위 제한이므로 이번 기능에서 교체한다. 전개 시 추가 점프는 여전히 금지하되 낮은 위치에서의 연속적인 상승 보정은 허용한다.
- 일정 하강을 전제로 한 이전 하강 시간 비교·필연적 낙사 인수 기준은 이번 목표 높이 수렴·유지 기준으로 대체한다. 경계 아래 진입 시 탈락 규칙 자체는 변경하지 않는다.
- 여러 섬 배치와 섬 사이 이동 검증, 온라인·전투·자기장·우승·방 단위 재경기는 후속 범위다. 기존 전개 시각 표시를 유지하며 신규 아트·효과음은 요구하지 않는다.
- `.specify/memory/constitution.md`는 미작성 템플릿이므로 예시 원칙을 확정 정책으로 적용하지 않는다.
