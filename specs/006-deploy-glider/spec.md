# Feature Specification: 공중 글라이더 전개와 이동

**Feature Branch**: `main` (브랜치 생성 훅 없음, 현재 브랜치 유지)

**Created**: 2026-11-01

**Status**: Draft — 명세 품질 검토 완료, 계획 수립 준비

**Input**: User description: "탑뷰 하늘섬 생존 액션 게임의 개발 순서 중 5단계: 공중에서 스페이스바를 누르면 글라이더를 펼치고 WASD로 이동하도록 구현. 6단계의 정해진 비행 높이로 자연스럽게 맞추기는 후속 작업이다."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 공중에서 글라이더 펼치기 (Priority: P1)

플레이어는 섬에서 점프하거나 걸어서 떨어진 뒤 스페이스바를 새로 눌러 글라이더를 펼치고, 일반 추락보다 천천히 내려가며 이동할 기회를 얻는다.

**Why this priority**: 지상 점프와 구별되는 공중 조작이 이번 단계의 핵심이다.

**Independent Test**: 기존 섬에서 점프 상승 중·정점 부근·하강 중 및 걸어서 이탈한 직후 각각 스페이스바를 새로 눌러 전개와 하강을 관찰한다.

**Acceptance Scenarios**:

1. **Given** 실제 섬 표면에 서 있는 생존 플레이어, **When** 스페이스바를 누르고 공중까지 유지하면, **Then** 기존 높이로 한 번 점프하며 글라이더는 자동으로 펼쳐지지 않는다.
2. **Given** 낙사 경계 이상 높이에서 상승·정점·하강 중인 생존 플레이어, **When** 스페이스바를 해제한 뒤 새로 누르면, **Then** 글라이더가 한 번 펼쳐지고 탑뷰에서 전개 상태를 확인할 수 있다. 추가 점프나 위쪽 도약 없이 전개 높이에서 완만한 하강을 시작한다.
3. **Given** 점프하지 않고 섬 밖으로 걸어 나간 생존 플레이어, **When** 공중에서 스페이스바를 새로 누르면, **Then** 점프 이력 없이도 글라이더가 펼쳐진다.
4. **Given** 글라이더가 펼쳐진 플레이어, **When** 스페이스바를 유지하거나 반복해서 누르면, **Then** 재전개·추가 점프·접기가 발생하지 않으며 기존 글라이딩을 계속한다.
5. **Given** 같은 출발 높이에서 무입력으로 떨어지는 두 번의 시험, **When** 한 번은 글라이더 없이, 다른 한 번은 같은 높이에서 글라이더를 펼쳐 동일한 하단 높이까지 내려가면, **Then** 글라이딩한 시험의 하강 시간이 더 길고 두 경우 모두 하강한다.

### User Story 2 - 글라이딩 방향을 조작하고 착지하기 (Priority: P1)

플레이어는 글라이딩 중에도 기존 화면 기준 WASD로 이동하고 방향을 바꾸어 섬 위로 돌아오며, 착지하면 다시 지상 이동과 점프를 한다.

**Why this priority**: 글라이더를 펼치는 것만이 아니라 원하는 위치로 조작하여 착지하는 흐름이 필요하다.

**Independent Test**: 섬 위 점프에서 전개한 뒤 8방향 이동·방향 변경·입력 해제를 시험하고 섬 표면에 착지한 후 새 점프를 수행한다.

**Acceptance Scenarios**:

1. **Given** 글라이딩 중인 플레이어, **When** WASD 또는 두 인접 방향 키를 누르면, **Then** 기존 탑뷰 화면 기준 해당 방향으로 이동하며 대각선 최고 속도는 단일 방향 최고 속도를 초과하지 않는다.
2. **Given** 글라이딩 중 이동하는 플레이어, **When** 방향을 바꾸거나 모든 이동 키를 놓으면, **Then** 기존 공중 수평 이동의 가속·감속·방향 전환 규칙으로 반응하며 키 해제 후 계속 자동 전진하지 않는다. 완만한 하강은 계속된다.
3. **Given** 섬 표면 위로 하강 중인 글라이더 플레이어, **When** 발이 걸을 수 있는 표면에 닿으면, **Then** 착지와 함께 글라이더가 닫히고 기존 지상 이동과 새 스페이스바 점프가 가능하다.
4. **Given** 섬 옆면에만 접촉한 글라이더 플레이어, **When** 발아래 지지가 없으면, **Then** 착지하거나 글라이더가 닫히지 않고 공중에 남는다.
5. **Given** 글라이더를 펼치지 않은 플레이어, **When** 기존 지상 이동·점프·공중 이동·착지를 수행하면, **Then** 기존 조작과 탑뷰 추적은 변경되지 않는다.

### User Story 3 - 글라이딩 후 낙사와 재시작 반복하기 (Priority: P2)

플레이어는 글라이딩해도 낙사 경계를 넘으면 탈락하며, R 키로 복귀하여 전개 시험을 반복한다. 과거 입력이나 전개 상태가 다음 시도에 남지 않는다.

**Why this priority**: 혼자 반복 검증하는 기존 흐름과 탈락 규칙을 유지해야 한다.

**Independent Test**: 글라이딩으로 섬 밖에서 낙사한 후 R 키로 재시작하고, 점프·전개·착지 및 재탈락을 반복한다.

**Acceptance Scenarios**:

1. **Given** 글라이딩 중인 생존 플레이어, **When** 발 위치가 낙사 경계보다 낮아지면, **Then** 기존 규칙으로 탈락하고 글라이더가 닫히며 탈락·R 키 안내가 표시된다. 경계와 같은 높이는 그 이유만으로 탈락하지 않는다.
2. **Given** 경계 아래 진입과 공중 스페이스바 입력이 겹친 플레이어, **When** 상태를 판정하면, **Then** 탈락이 우선하며 전개로 탈락이 취소되지 않는다.
3. **Given** 탈락한 플레이어, **When** WASD·스페이스바를 입력하면, **Then** 이동·점프·전개가 발생하지 않는다. 이후 새 R 입력은 기존 시작 위치·방향으로 한 번 복귀시킨다.
4. **Given** 탈락 중 스페이스바를 유지한 플레이어, **When** R 키로 재시작하면, **Then** 글라이더와 이전 낙하 움직임이 남지 않고 자동 점프·전개가 발생하지 않는다. 해제 후 새 지상 입력은 점프하고, 다시 해제한 뒤 새 공중 입력은 글라이더를 펼친다.
5. **Given** 공중 또는 글라이딩 중인 플레이어, **When** 초점 상실 후 복귀하거나 비활성화 후 재활성화하면, **Then** 과거 스페이스바 입력이 새 점프·전개로 실행되지 않는다. 생존한 공중 플레이어의 기존 전개 여부는 유지되며, 플레이가 진행되는 동안 해당 상태의 수직 이동은 계속된다. 이동 재개는 기존 키 해제 조건을 따른다.

### Edge Cases

- 지상 점프 한 번의 누름을 공중 전개 입력으로 중복 처리하지 않는다. 빠른 누름·해제도 유효한 새 공중 입력이면 한 번 처리한다.
- 착지와 새 스페이스바 입력이 같은 시점에 판정되면 실제 발아래 지지가 있으면 지상 점프만, 없으면 공중 전개만 허용한다. 한 입력으로 두 동작을 실행하지 않는다.
- 착지 전에 글라이딩 중 받은 추가 전개 입력은 착지 후 점프로 저장하지 않는다. 착지까지 키를 유지해도 자동 점프하지 않는다.
- 빠른 추락 도중 전개해도 높이를 순간 이동시키거나 낙사 경계 아래에서 구제하지 않는다.
- 글라이딩 중 입력을 놓아도 낙사 경계 위의 허공에서 정지하거나 목표 높이로 상승하지 않는다.
- 반복 착지·탈락·재시작 후 글라이더 표시가 중복되거나 지상에 남지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 생존한 지상 플레이어의 새 스페이스바 입력은 기존 고정 높이 점프만 실행해야 한다. 동일 누름의 유지가 공중 전개를 유발해서는 안 된다.
- **FR-002**: 생존한 공중 플레이어는 상승·정점·하강 및 걸어서 섬을 이탈한 경우 모두 새 스페이스바 입력으로 글라이더를 한 번 펼칠 수 있어야 한다. 실제 발아래 지지로 지상·공중을 구분해야 한다.
- **FR-003**: 전개 시 높이의 순간 변경·추가 점프·상승 가속 없이, 전개 시점부터 정해진 양의 하강 속도로 내려가야 한다. 그 속도는 같은 높이 구간의 비전개 추락보다 하강 시간을 늘릴 만큼 느려야 한다. 목표 비행 높이의 유지·상승·높이 보정은 제공하지 않아야 한다.
- **FR-004**: 글라이딩 중 기존 공중 수평 이동의 화면 기준 WASD 방향, 최고 속도, 가속·감속, 방향 전환과 대각선 속도 제한을 유지해야 한다. 입력 해제 시 기존 감속 규칙으로 정지해야 하며 자동 전진을 추가하지 않아야 한다.
- **FR-005**: 플레이어는 탑뷰에서 전개·비전개 상태를 시각적으로 구별할 수 있어야 한다. 글라이딩 중 새 스페이스바 입력은 무시하고 재전개·접기·추가 점프를 실행하거나 이후 상태에 저장해서는 안 된다.
- **FR-006**: 실제 걸을 수 있는 표면에 하강 착지하면 글라이더를 자동으로 닫고 기존 지상 이동·점프를 복원해야 한다. 옆면 접촉이나 출발 지면 높이만으로 착지시켜서는 안 된다.
- **FR-007**: 기존 발 위치 기준 낙사 판정을 글라이딩에도 적용해야 한다. 발이 경계보다 엄격히 낮으면 탈락을 우선하며 글라이더를 닫고 조작을 차단하고 기존 탈락·재시작 안내를 유지해야 한다.
- **FR-008**: 기존 새 R 입력 재시작 규칙을 유지하고, 복귀 시 전개 여부·글라이더 표시·이전 수직 움직임·미처리 스페이스바 입력을 초기화해야 한다. 탈락 중 유지한 스페이스바로 자동 점프·전개해서는 안 되며 유지 중인 WASD는 기존 재시작 정책을 따라야 한다.
- **FR-009**: 초점 상실·비활성화 시 미처리 입력과 수평 조작을 정리하고 복귀만으로 새 동작을 실행하지 않아야 한다. 복귀 시 생존 공중 플레이어의 전개 여부는 유지하고 기존 키 해제 후 새 입력 정책을 적용해야 한다.
- **FR-010**: 유효한 짧은 공중 누름·해제를 누락하거나 중복 처리하지 않아야 한다. 지지·낙사 상태를 확인하여 한 입력에는 점프 또는 전개 중 최대 하나만 허용하고 탈락이 겹치면 둘 다 실행하지 않아야 한다.
- **FR-011**: 비전개 상태의 기존 이동·점프·추락·착지, 낙사 높이, 최초 시작 위치·방향, 재시작과 탑뷰 카메라를 유지해야 한다. 글라이딩은 기존 섬 하나와 로컬 플레이어 한 명으로 반복 시험 가능해야 한다.

### Key Entities *(include if feature involves data)*

- **플레이어 동작 상태**: 지상·비전개 공중·글라이딩·탈락을 구별하며 허용 조작을 결정한다. 글라이딩은 생존 공중 상태에서만 가능하다.
- **글라이딩 특성**: 일반 추락보다 느린 양의 하강 속도와 기존 공중 수평 이동 특성. 목표 절대 높이는 포함하지 않는다.
- **지지 표면과 낙사 경계**: 착지·전개 종료와 생존·탈락을 각각 결정하는 기존 기준이다.
- **전개 표시**: 탑뷰에서 글라이딩 여부를 식별하는 시각 정보. 착지·탈락·재시작 때 제거한다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 점프 상승·정점·하강·걸어서 이탈의 네 경우에서 새 공중 스페이스바 입력을 각각 5회 시험해 20회 모두 0.2초 이내 전개를 확인한다. 지상 점프 키 유지와 글라이딩 중 반복 입력은 각각 5회 시험하여 자동 전개·추가 점프·접기는 0회다.
- **SC-002**: 같은 시작 높이와 하단 높이 사이의 비전개 추락·글라이딩을 5쌍 비교하여 모든 쌍에서 글라이딩의 하강 시간이 더 길다. 전개에 따른 순간 높이 이동·새 도약·허공 정지·목표 높이 상승은 0회다.
- **SC-003**: 글라이딩 중 8방향 이동·방향 전환·입력 해제를 각각 5회 시험하여 방향 오류·대각선 최고 속도 증가·해제 후 자동 전진은 0회다. 모든 시험에서 탑뷰로 플레이어와 전개 상태를 식별할 수 있다.
- **SC-004**: 섬 위 전개 후 착지·새 점프를 10회 수행하여 모두 착지와 동시에 글라이더 표시가 제거되고 새 점프가 가능하다. 옆면 접촉만 하는 시험 5회에서 허위 착지·전개 종료는 0회다.
- **SC-005**: 글라이딩 중 낙사 경계 위·동일·아래를 각각 5회 시험하여 위·동일의 오탈락은 0회, 아래의 탈락은 5회다. 아래 진입과 전개 입력이 겹치는 5회에서도 모두 탈락하고 1초 이내 기존 안내를 확인한다.
- **SC-006**: 실행 종료 없이 `점프 또는 섬 이탈 → 전개 → 낙사 → R 재시작`을 20회 연속 완료한다. 매회 유효 R 입력 후 2초 이내 다시 조작 가능하며 글라이더 잔류·중복 표시·자동 점프·자동 전개는 0회다.
- **SC-007**: 빠른 공중 누름·해제, 착지와 새 입력 겹침, 착지까지 키 유지, 탈락 중 키 유지 후 복귀, 초점 전환 및 비활성화·재활성화를 각각 5회 시험하여 누락·중복 동작·과거 입력 재실행은 0회다. 각 시험 후 허용 조건에서 새 점프·전개는 모두 가능하다.
- **SC-008**: 비전개 상태의 기존 이동·점프·낙사·재시작 인수 기준 중 이번 기능으로 명시적으로 확장하지 않은 항목을 100% 유지한다. 실제 검증 통과와 미검증 결과는 분리 기록한다.

## Assumptions

- 범위는 사용자 로드맵의 5단계다. 6단계 목표 비행 높이로 상승·하강 보정, 7단계 여러 섬 배치와 섬 사이 이동 검증, 온라인·전투·자기장·우승·방 단위 재경기는 제외한다.
- 6단계 전까지 유용한 최소 글라이딩의 기본값으로 일정한 완만한 하강을 사용한다. 상승 중 전개해도 추가 상승 없이 그 높이에서 하강으로 바뀐다. 구체적인 하강 속도 수치는 계획·플레이 검증에서 정하되 SC-002를 충족해야 한다.
- 수평 조작은 기존 공중 이동을 재사용하는 사용자 경험으로 정의하며 별도 속도 증가, 자동 전진, 자원 소모, 비행 시간 제한, 수동 접기·재전개는 요구하지 않는다. 전개는 착지 또는 탈락까지 유지한다.
- 전개 여부를 식별할 최소 시각 피드백만 요구한다. 완성형 글라이더 아트·애니메이션·효과음·전용 안내 화면은 요구하지 않는다.
- `specs/001-island-movement-camera/spec.md`부터 `specs/005-refactor-player-input-state/spec.md`까지를 선행 기준으로 삼는다. 이번 명세는 실제 구현 완료나 기존 검수 통과를 보증하지 않는다.
- 앞선 명세의 ‘공중 스페이스바는 아무 동작도 하지 않는다/글라이더 미제공’은 단계별 범위 제한이었다. 이번 명세는 그 부분만 전개로 확장하며 추가 공중 점프 금지는 유지한다.
- 한 명의 로컬 키보드 플레이어와 기존 고정 하늘섬 하나를 대상으로 한다. 재시작할 안전한 최초 위치와 기존 낙사 경계가 준비되어 있다고 가정한다.
- `.specify/memory/constitution.md`는 미작성 템플릿이므로 확정된 추가 프로젝트 원칙을 임의로 적용하지 않는다.
