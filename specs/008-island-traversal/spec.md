# Feature Specification: 같은 높이의 하늘섬 사이 점프·글라이딩 이동

**Feature Branch**: `main` (브랜치 생성 훅 없음, 현재 브랜치 유지)

**Created**: 2026-11-01

**Status**: Draft — 명세 품질 검토 완료, 계획 수립 준비

**Input**: User description: "이제 '7. 같은 높이에 하늘섬 여러 개를 배치하고 점프와 글라이딩으로 섬 사이 이동 테스트.' 이거 지금 디렉토리의 프로젝트에 기능 추가 구현할 차례야."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 짧은 섬 사이 간격을 점프로 건너기 (Priority: P1)

플레이어는 같은 높이에 놓인 하늘섬과 사이의 빈 공간을 구별하고, 가까운 섬으로 점프해 착지한 뒤 계속 걷거나 다시 점프한다.

**Why this priority**: 한 섬 안의 이동을 실제 섬 사이 이동으로 확장하는 최소 플레이 흐름이다.

**Independent Test**: 시작 섬 A와 가까운 섬 B 사이를 글라이더 없이 왕복하며 실제 착지와 착지 후 조작을 확인한다.

**Acceptance Scenarios**:

1. **Given** 게임을 처음 시작한 플레이어, **When** 주변을 살펴보면, **Then** 같은 높이의 고정 섬이 3개 이상 있고 섬 사이에 걸어서 통과할 수 없는 빈 공간이 보이며 시작 위치는 섬 A의 안전한 표면 위다.
2. **Given** 섬 A의 짧은 구간 출발 가장자리 안쪽에 선 플레이어, **When** 섬 B 방향으로 이동하며 지상에서 Space를 새로 누르고 공중에서 다시 누르지 않으면, **Then** 글라이더 없이 섬 B 위에 착지한다. 반대 방향도 같은 방식으로 가능하다.
3. **Given** 섬 B에 착지한 플레이어, **When** WASD로 걷거나 Space를 새로 누르면, **Then** 해당 섬에서 지상 이동과 새 점프가 가능하다.
4. **Given** 섬 사이 빈 공간 위에서 발아래 지지가 없는 플레이어, **When** 기존 섬 표면 높이를 지나거나 옆면에 닿으면, **Then** 지상으로 잘못 판정하지 않으며 공중 이동 또는 낙하를 계속한다.

---

### User Story 2 - 긴 구간을 글라이딩하고 목적지에 착지하기 (Priority: P1)

플레이어는 점프만으로 닿지 않는 섬 C로 글라이딩하고, 목적지 표면 위에서 Space를 놓아 내려앉는다. 다른 섬에서도 같은 조작으로 이동을 이어간다.

**Why this priority**: 점프와 구별되는 글라이딩의 이동 가치를 실제 섬 배치에서 검증한다.

**Independent Test**: B–C 구간에서 비전개 점프의 도달 불가를 먼저 확인하고, 점프 후 새 공중 Space 유지로 왕복한 뒤 목적지 위에서 해제·착지한다.

**Acceptance Scenarios**:

1. **Given** 섬 B의 긴 구간 출발 가장자리 안쪽에 선 플레이어, **When** 섬 C 방향으로 최대 수평 속도로 점프하되 글라이더는 펼치지 않으면, **Then** 섬 C 표면에 착지하지 못한다. 같은 구간은 글라이딩으로 건널 수 있다.
2. **Given** 섬 B에서 점프한 플레이어, **When** 지상 점프 입력을 해제한 후 공중에서 Space를 새로 누르고 유지하며 섬 C 방향으로 이동하면, **Then** 기존 목표 발 높이 2m를 향해 보정하면서 빈 공간을 건너 섬 C 위에 도달한다. 반대 방향도 가능하다.
3. **Given** 섬 C 표면 위에서 Space를 유지 중인 플레이어, **When** 이동 입력만 놓으면, **Then** 수평 이동은 기존 규칙으로 감속하며 글라이딩 높이는 유지한다. 섬 위라는 이유만으로 접거나 착지하지 않는다.
4. **Given** 섬 C 표면 위의 플레이어, **When** Space를 놓고 표면 안에 머무르면, **Then** 글라이더를 접고 자연스럽게 하강해 착지하며 지상 이동과 새 점프를 할 수 있다.
5. **Given** 비행 중인 플레이어, **When** 방향을 바꾸거나 목적지를 지나치면, **Then** 기존 WASD 조작으로 되돌아올 수 있고 카메라는 플레이어를 계속 추적한다. 섬으로 자동 이동하거나 순간 이동하지 않는다.

---

### User Story 3 - 이동 실패 후 시작 섬에서 반복 시험하기 (Priority: P2)

플레이어는 섬 사이 이동에 실패해 낙사하면 기존 R 재시작으로 시작 섬에 복귀하여 같은 배치에서 다시 시험한다.

**Why this priority**: 이동 성공과 실패를 실행 종료 없이 반복 검증할 수 있어야 한다.

**Independent Test**: 섬 사이에서 글라이더를 접어 낙사하고 R로 복귀한 뒤 짧은 구간과 긴 구간을 다시 이동한다.

**Acceptance Scenarios**:

1. **Given** 빈 공간에서 글라이더를 접고 떨어지는 플레이어, **When** 발 위치가 기존 낙사 경계보다 낮아지면, **Then** 기존 탈락 안내와 조작 차단이 적용된다. 경계와 같은 높이만으로 탈락하지 않는다.
2. **Given** 시작 섬 이외의 섬에서 출발해 탈락한 플레이어, **When** R을 새로 누르면, **Then** 최초 시작 섬 A의 기존 시작 위치·방향으로 복귀한다. 마지막 방문 섬을 새 시작점으로 삼지 않는다.
3. **Given** 탈락 후 재시작한 플레이어, **When** 새 이동·점프·공중 전개를 입력하면, **Then** 과거 비행 상태나 유지 입력의 자동 실행 없이 새 시도를 수행하며 섬 배치는 바뀌지 않는다.

### Edge Cases

- 섬 가장자리에서 발아래 지지가 사라지면 공중으로 전환하며 보이지 않는 연결 바닥이나 다리가 없어야 한다.
- 섬 옆면 접촉은 착지가 아니며 표면 위로 하강해 실제 지지를 얻었을 때만 착지한다. 섬을 관통하거나 위로 순간 이동하지 않는다.
- 목적지 위에서 Space를 계속 유지하면 발 높이 2m에 머무는 것이 정상이다. 착지를 위해 키를 놓아야 하며 자동 접기는 추가하지 않는다.
- 목적지 가장자리 밖에서 키를 놓거나 수평 관성으로 이탈하면 착지에 실패할 수 있다. 낙사 경계 위에서는 기존 규칙대로 새 공중 누름으로 재전개할 수 있지만 이미 탈락한 뒤에는 구제하지 않는다.
- 점프 입력 유지: 지상에서 누른 Space를 착지까지 유지해도 글라이더가 자동 전개되거나 착지 후 다시 점프하지 않는다.
- 글라이더 입력 유지: 공중에서 새로 누른 Space를 유지하면 목적지 위에서도 비행을 계속한다. Space를 해제해야 하강·착지하며, 착지 후 새 누름으로만 점프한다.
- 재시작 중 누르고 있던 입력이 자동 점프·자동 전개를 만들지 않는다.
- 이동 중 초점을 잃으면 기존 입력 정리·글라이더 접기 규칙을 유지한다. 복귀만으로 자동 재전개하지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 기존 플레이 공간에 고정 하늘섬을 총 3개 이상 제공해야 한다. 모든 걸을 수 있는 상단 표면은 기존 시작 섬과 동일한 높이인 0m이며 섬끼리 겹치거나 다리로 연결되지 않아야 한다.
- **FR-002**: 최초 시작 위치·방향과 안전한 지지를 유지해야 한다. 재시작은 방문한 섬과 무관하게 최초 시작 섬 A로 복귀하고 섬 배치는 시도 사이에 동일해야 한다.
- **FR-003**: A–B에는 기존 점프와 수평 이동만으로 양방향 착지 가능한 짧은 구간을, B–C에는 점프만으로는 양방향 착지가 불가능하지만 기존 글라이딩으로는 양방향 이동 가능한 긴 구간을 제공해야 한다. 간격은 조작 성능을 변경하지 않고 이 조건을 만족하도록 정한다.
- **FR-004**: 각 목적지에는 외곽에 간신히 걸치는 접촉이 아닌, 착지 후 걷기·새 점프 및 다음 이동 준비가 가능한 표면 공간이 있어야 한다.
- **FR-005**: 모든 섬에 기존 지지·충돌·착지 규칙을 동일하게 적용해야 한다. 빈 공간이나 옆면을 지상으로 판정하거나 섬을 관통해서는 안 된다.
- **FR-006**: 지상 새 Space는 점프, 해제 후 새 공중 Space 유지는 글라이딩, Space 해제는 접기·중력 낙하라는 최신 조작을 유지해야 한다. 글라이딩 목표 발 높이 2m, 기존 점프 높이·수평 이동·가속·감속·대각선 제한을 바꾸지 않아야 한다.
- **FR-007**: 플레이어는 글라이딩으로 목적지 위에 도달한 뒤 키를 놓아 하강 착지하고 다시 지상 이동·점프·다른 섬으로 이동할 수 있어야 한다. 목적지 위라는 이유만으로 자동 착지·접기·높이 변경을 수행해서는 안 된다.
- **FR-008**: 탑뷰 카메라는 어느 섬 위 또는 섬 사이에 있어도 기존 방식으로 플레이어를 추적해야 한다. 접근 중인 목적지의 가장자리와 사이 빈 공간을 이동 방향에서 확인할 수 있어야 하며 모든 섬을 한 화면에 동시에 표시할 필요는 없다.
- **FR-009**: 섬 사이에서도 기존 낙사 경계·탈락 안내·조작 차단·R 재시작·입력 초기화·초점 상실 규칙을 보존해야 한다. 체크포인트나 자동 구조를 추가하지 않아야 한다.
- **FR-010**: 짧은 구간 점프 왕복, 긴 구간 비전개 점프 실패와 글라이딩 왕복·접기 착지, 여러 섬 연속 이동 및 낙사·재시작에 대한 재현 가능한 검증 절차와 결과를 남겨야 한다. 실제 통과·실패·미검증을 구별하고 관찰 없이 플레이 검증 통과로 기록해서는 안 된다.

### Key Entities *(include if feature involves data)*

- **하늘섬**: 같은 상단 높이를 가진 고정 지형. 시작 섬 A, 가까운 섬 B, 긴 구간 목적지 C를 포함하며 각각 실제 착지와 이동 가능한 표면을 제공한다.
- **이동 구간**: 두 섬의 가장자리 사이 빈 공간. 점프로 왕복 가능한 짧은 구간과 글라이딩이 필요한 긴 구간으로 구별한다.
- **이동 시도**: 출발 섬·목적지·이동 방식·착지 또는 낙사 결과를 갖는 한 번의 시험. 재시작해도 배치는 유지된다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 첫 시작과 R 재시작 5회 모두 총 3개 이상의 분리된 섬, 모든 상단 표면 높이 0m, 시작 위치의 안전한 지지 및 동일한 섬 배치를 확인한다.
- **SC-002**: 정해진 출발 지점과 이동 방향에서 A→B 및 B→A 비전개 점프를 각각 5회 수행하여 10회 모두 착지하고, 착지 후 걷기와 새 점프가 가능하다.
- **SC-003**: B→C 및 C→B에서 출발 가장자리 안쪽까지 최대 수평 속도로 접근해 목적지 방향으로 비전개 점프를 각각 5회 수행한다. 10회 모두 목적지 표면에 착지하지 못한다. 같은 출발 지점에서 점프·새 공중 전개·이동·해제 착지를 각각 5회 수행하여 10회 모두 성공한다.
- **SC-004**: 목적지 표면 위에서 이동 입력을 놓고 Space를 유지하는 시험 5회 모두 감속 후 발 높이 2±0.1m를 10초 유지한다. 이어 Space를 놓고 표면 안에 머무르면 5회 모두 3초 이내 착지하며, 자동 접기·표면 순간 이동은 0회다.
- **SC-005**: A→B→C→B→A 연속 이동을 3회 완료한다. 각 섬에서 착지·걷기·새 점프가 가능하고 전 구간에서 플레이어와 접근 중인 목적지 가장자리·빈 공간을 탑뷰로 확인할 수 있다. 잘못된 지상 판정·지형 관통·추적 이탈은 0회다.
- **SC-006**: 섬 사이에서 `접기 → 낙사 → R 재시작 → 새 점프·전개`를 10회 반복한다. 모두 기존 낙사 규칙을 따르고 유효 R 입력 후 2초 이내 최초 시작 위치에서 다시 조작 가능하다. 이전 글라이더·속도 잔류와 유지 입력에 의한 자동 동작은 0회다.
- **SC-007**: SC-001~SC-006의 출발 조건·조작 순서·시도별 결과를 기록하고 미검증 항목을 명시한다. 관찰자는 짧은 구간에서의 점프, 긴 구간에서의 글라이딩 및 목적지에서 접고 착지하는 세 흐름을 구별할 수 있다고 기록한다.

## Assumptions

- 이번 범위는 사용자 로드맵 7단계의 로컬 플레이어 한 명을 위한 고정 배치 이동 시험이다. 이번 명세 작성 자체가 기능 구현 또는 실제 플레이 검증 완료를 의미하지 않는다.
- ‘여러 개’의 최소 유효 기본값은 총 3개이며, 짧은 구간과 긴 구간을 각각 하나 이상 제공한다. 구체적인 가로 크기·좌표·간격은 기존 조작을 유지하면서 성공 기준을 충족하도록 계획 단계에서 정한다.
- 최신 선행 기준은 `specs/007-glide-height-control/spec.md`의 사용자 수정 사항이다. Space 유지 전개·해제 접기·공통 목표 발 높이 2m가 이전 단계의 전개 유지·일정 하강 규칙보다 우선한다.
- 기존 표면 높이 0m와 점프 높이 2m를 유지한다. 이번 단계는 섬 배치와 이동 검증의 확장이며 글라이딩 높이를 섬에 맞춰 새로 계산하거나 이동 성능을 재설계하지 않는다.
- 기존 섬 하나만으로 검증한다는 선행 명세의 범위 제한은 여러 섬으로 확장한다. 기존 이동·낙사·재시작·카메라 규칙은 명시된 확장 이외에는 변경하지 않는다.
- 무작위 생성, 다른 고도의 섬, 움직이는 섬, 체크포인트, 자동 경로 이동, 온라인·전투·자기장·우승 판정 및 신규 아트·효과음은 제외한다. 별도 목표 안내 화면이나 새 조작 키도 요구하지 않는다.
- 검수는 조작 순서를 아는 시험자가 재현 가능한 조건에서 수행하며, 실패 구간을 확인하기 위한 비전개 점프는 글라이더를 사용하지 않는다.
