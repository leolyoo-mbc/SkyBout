# Feature Specification: 하늘섬 추락과 낙사 탈락

**Feature Branch**: `main` (브랜치 생성 훅 없음, 현재 브랜치 유지)

**Created**: 2026-10-30

**Status**: Draft — 범위 확정, 계획 수립 준비 완료

**Input**: User description: "같은 높이에 떠 있는 하늘섬을 오가는 탑뷰 생존 액션 게임. 1. 하늘섬과 WASD 이동·탑뷰 카메라. 2. 지상 스페이스바 고정 높이 점프·착지. 3. 섬 밖 추락과 정해진 낙사 높이 아래에서 탈락. 4. 탈락 후 혼자 반복 시험할 재시작. 5. 공중 스페이스바 글라이더와 WASD 조작. 글라이딩 중 정해진 비행 높이로 자연스럽게 보정. 온라인 대전·자기장·최후의 1인 생존은 전체 게임의 방향."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 섬 밖으로 나가면 추락 (Priority: P1)

플레이어는 기존 WASD 이동이나 점프로 섬을 벗어나면 발아래 지면이 없다는 것을 확인하고 아래로 떨어진다. 섬 높이의 허공에 서거나 보이지 않는 벽에 막히지 않는다.

**Why this priority**: 안전한 섬과 위험한 공중을 구분하는 기본 규칙이며 낙사 판정의 선행 조건이다.

**Independent Test**: 기존 섬의 가장자리를 걸어서 벗어나는 경우와 점프로 벗어나는 경우를 각각 관찰한다.

**Acceptance Scenarios**:

1. **Given** 섬 위에서 이동 중인 생존 플레이어, **When** 가장자리를 넘어 발아래 표면이 없어지면, **Then** 지상 상태를 벗어나 하강하며 허공에 멈추지 않는다.
2. **Given** 섬 밖으로 향하는 점프 중인 플레이어, **When** 정점 이후 아래에 착지 표면이 없으면, **Then** 출발 지면 높이를 지나 계속 하강한다.
3. **Given** 낙사 높이 위에서 하강하는 플레이어, **When** 걸을 수 있는 섬 표면 위로 돌아와 발이 표면에 닿으면, **Then** 착지하고 지상 이동과 새 점프를 할 수 있다.
4. **Given** 섬 밖 공중에 있는 생존 플레이어, **When** 스페이스바를 반복해서 누르면, **Then** 추가 점프나 글라이더 전개 없이 추락을 계속한다.

---

### User Story 2 - 낙사 높이 아래에서 탈락 (Priority: P1)

플레이어는 정해진 높이 아래로 추락하면 탈락했다는 것을 확인한다. 탈락 후에는 이동이나 점프로 생존 플레이를 계속할 수 없다.

**Why this priority**: 추락에 명확한 결과를 주어 이후 생존 게임의 탈락 규칙을 마련한다.

**Independent Test**: 섬에서 떨어져 설정한 경계 높이의 위·동일·아래에서 생존 여부를 확인하고 탈락 후 조작을 시도한다.

**Acceptance Scenarios**:

1. **Given** 플레이어 기준 높이가 낙사 높이 이상인 상태, **When** 다른 탈락 사유 없이 하강하면, **Then** 그 높이에 있다는 이유만으로 탈락하지 않는다.
2. **Given** 생존 플레이어가 추락 중인 상태, **When** 기준 높이가 낙사 높이보다 낮아지면, **Then** 탈락으로 전환되고 플레이 화면에 탈락 사실이 표시된다.
3. **Given** 이미 탈락한 플레이어, **When** WASD 또는 스페이스바를 반복 입력하거나 시간이 지나면, **Then** 생존 상태로 돌아오거나 추가 탈락이 반복 발생하지 않으며 플레이 조작도 실행되지 않는다.
4. **Given** 동일한 섬과 플레이어 시작 위치, **When** 낙사 높이를 다른 유효한 값으로 바꾸고 재실행하면, **Then** 새 경계 높이에 맞춰 탈락한다.

### Edge Cases

- 섬 옆면에 닿더라도 발아래 걸을 수 있는 표면이 없으면 착지가 아니며 계속 추락한다.
- 낙사 높이와 정확히 같은 높이에서는 생존하고, 아래로 넘어간 첫 판정에서 탈락한다. 빠른 하강으로 경계를 한 번에 지나쳐도 누락하지 않는다.
- 가장자리에서 공중으로 나간 후 스페이스바를 눌러도 지상 점프를 새로 시작하거나 글라이더를 펼치지 않는다.
- 같은 시점에 낙사 경계 아래 진입과 다른 상태 전환이 겹쳐도 탈락을 취소하지 않는다.
- 탈락 이후 계속 하강하거나 화면 밖으로 나가더라도 탈락 안내는 확인할 수 있어야 한다.
- 입력 초점을 잃었다가 복귀하는 것만으로 탈락 상태가 해제되거나 새 점프가 발생하지 않는다.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 발아래 걸을 수 있는 표면이 사라지면 플레이어를 공중 상태로 처리하고, 점프의 상승 구간 이후에는 아래 표면에 착지하거나 탈락할 때까지 하강시켜야 한다.
- **FR-002**: 섬 경계 밖의 허공을 지면으로 취급하거나 출발 지면 높이에 도달했다는 이유로 착지시켜서는 안 된다. 섬 옆면 접촉만으로 지상 상태를 부여해서도 안 된다.
- **FR-003**: 생존 중에는 기존 WASD 공중 수평 조작을 유지하고, 발아래 실제 표면에 하강 착지하면 기존 지상 이동과 새 점프를 허용해야 한다.
- **FR-004**: 낙사 높이는 섬과 동일한 기준에서 측정하는 절대 수직 높이여야 한다. 플레이어 높이는 발 위치로 판단하며, 발 위치가 경계보다 낮아졌을 때 탈락시켜야 한다. 경계와 같은 높이에서는 탈락시키지 않아야 한다.
- **FR-005**: 하강 중 경계를 한 번에 지나쳐도 첫 번째 경계 아래 판정에서 탈락을 처리해야 한다.
- **FR-006**: 탈락은 생존 상태에서 한 번만 발생해야 하며 탈락 이후 WASD 이동과 스페이스바의 플레이 동작을 차단해야 한다. 입력 또는 시간 경과만으로 생존 상태에 복귀해서는 안 된다.
- **FR-007**: 탈락하면 플레이어가 화면 안에 있는지와 무관하게 탈락 안내를 표시하고 유지해야 한다.
- **FR-008**: 낙사 높이를 조정하고 다시 실행하여 판정 위치를 비교할 수 있어야 한다. 초기 낙사 높이는 안전한 섬 표면보다 낮아야 하며 전용 설정 화면은 요구하지 않는다.
- **FR-009**: 생존 중 기존 탑뷰 시점과 점프·착지 조작을 유지해야 한다. 입력 초점 복귀가 탈락 해제나 새 점프를 일으켜서는 안 된다.
- **FR-010**: 공중에서 스페이스바를 눌러도 추가 점프나 글라이더 전개가 발생해서는 안 된다. 이번 단계에서는 탈락 후 자동 복귀나 게임 내 재시작을 제공하지 않는다.

### Key Entities *(include if feature involves data)*

- **플레이어 생존 상태**: 생존과 탈락을 구분한다. 생존 상태에서만 이동·점프·착지가 가능하다.
- **낙사 경계**: 발 위치와 비교하는 절대 높이. 이 높이보다 낮아지면 탈락하며 조정 가능하다.
- **지지 표면**: 플레이어가 서거나 하강 착지할 수 있는 하늘섬 표면. 경계 밖이나 옆면 접촉은 지지를 제공하지 않는다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 서로 다른 네 가장자리에서 걷기 이탈과 점프 이탈을 각각 5회, 총 40회 시험했을 때 모두 추락하고 허공 착지나 경계에 의한 이동 차단은 0회다.
- **SC-002**: 낙사 경계 바로 위·동일·바로 아래를 각각 5회 확인하여 위와 동일 높이에서의 오탈락은 0회, 아래 높이에서의 탈락은 5회다. 빠른 하강으로 경계를 지나치는 시험도 5회 모두 탈락해야 한다.
- **SC-003**: 탈락 시험 10회 모두 경계 아래 판정 후 1초 이내에 탈락 안내가 보인다. 이후 10초 동안 WASD와 스페이스바를 반복 입력해도 이동 재개·새 점프·자동 생존 복귀는 0회다.
- **SC-004**: 낙사 경계에 도달하기 전 섬 표면 위로 돌아오는 시험 5회와 섬 중앙 점프·착지 시험 10회 모두 정상 착지하고, 착지 후 이동과 새 점프를 할 수 있다. 섬 밖 공중에서 스페이스바를 반복 입력하는 시험 5회에서 추가 점프와 글라이더 전개는 모두 0회다.
- **SC-005**: 서로 다른 유효 낙사 높이 두 값으로 각각 5회 시험하면 10회 모두 해당 경계 아래에서만 탈락한다. 생존 중 탑뷰로 추락을 확인할 수 있고 화면 밖으로 나가도 탈락 안내가 유지된다.

## Assumptions

- 기존 `specs/001-island-movement-camera/spec.md`와 `specs/002-ground-jump/spec.md`의 이동·카메라·점프·착지를 선행 기반으로 삼는다. 이 명세는 그 기능이 실제로 완료되었다고 보증하지 않는다.
- 사용자는 범위 확인에서 A를 선택했다. 이번 기능은 3단계인 섬 밖 추락과 낙사 높이 아래 탈락에 한정한다. 4단계 게임 내 재시작과 5단계 글라이더·비행 높이 보정은 후속 기능으로 제외한다.
- 한 명의 로컬 키보드 플레이어와 기존 고정 하늘섬 하나로 검증한다. 전체 게임 방향인 여러 섬, 온라인 대전, 전투, 자기장, 최후 생존자 판정은 이번 초안 범위 밖이다.
- 발 위치를 낙사 높이의 비교 기준으로 사용한다. 구체적인 초기 높이 수치는 플레이하며 조정하되 섬 표면 아래에 둔다.
- 반복 검증은 기존 실행 종료·재실행으로 수행한다. 게임 내 재시작 기능이 이미 있다는 가정은 하지 않는다.
- 경사면, 이동 발판, 별도 추락 연출·효과음 및 관전 기능은 요구하지 않는다. 탈락 안내의 표현 방식은 지정하지 않는다.
- `.specify/memory/constitution.md`는 미작성 템플릿이므로 확정된 추가 프로젝트 원칙은 없다.
