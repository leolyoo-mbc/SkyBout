# Contract: 플레이어 추락·탈락과 화면 안내

이 계약은 로컬 키보드 플레이어의 입력·상태·화면 동작이다. 외부 HTTP/네트워크 API나 저장 포맷을 추가하지 않는다.

## 기존 연결 보존

- 씬: `Assets/Scenes/SampleScene.unity`의 기존 Player, Ground, Main Camera.
- 입력: `Assets/Player_Actions.inputactions`, Player 맵, Move/Jump 액션, PlayerInput SendMessages. 기존 액션 ID·바인딩·스킴은 유지한다.
- 생존 이동: W/S는 화면 기준 앞/뒤, A/D는 좌/우. 가속·감속·방향 전환·대각선 최고 속도와 공중 조작을 유지한다.
- 점프: 실제 지지 표면에 서 있을 때 새로운 Space 누름 1회만 점프한다. 공중 Space, 홀드 및 착지 전 입력 예약으로 새 점프를 만들지 않는다. 글라이더는 없다.
- 카메라: `TopDownCameraFollow`의 기존 목표와 설정을 유지한다. 커서 위치와 무관한 추적 동작을 변경하지 않는다.

## 낙사 판정

| 조건 | 관찰 결과 |
| --- | --- |
| 발밑 지지 상실 | 중력에 따른 공중 이동. 허공·옆면을 지면으로 취급하지 않음 |
| 생존, 발 Y > 경계 | 낙사 탈락 없음 |
| 생존, 발 Y = 경계 | 낙사 탈락 없음 |
| 생존, 발 Y < 경계 | 해당 물리 판정에서 탈락 1회, 점프·이동 처리보다 우선 |
| 한 물리 스텝에 경계를 지나침 | 다음 경계 아래 관찰에서 누락 없이 탈락 |
| 탈락 이후 입력·초점 복귀·재활성화 | 탈락 유지, 이동/점프 재개 없음 |
| 실행 종료·재실행 | 새 인스턴스가 안전한 기존 시작 위치에서 생존으로 시작 |

Inspector의 `fallDeathHeight`는 유한한 월드 Y다. 초기값은 -10이며 SampleScene 표면 Y=0보다 낮다. 값 조정은 Play를 중지한 뒤 수행하고 다시 실행한다. 전용 설정 화면은 없다.

## 탈락 조작 제한

- 탈락 진입에서 수평 속도·이동 입력·보류 점프·지지 상태를 초기화한다.
- 탈락 이후 OnMove와 OnJump로 게임플레이 동작을 요청할 수 없다. 입력 메시지를 받는 것 자체를 금지할 필요는 없다.
- 동일 인스턴스에서 높이를 다시 경계 위로 옮겨도 생존 복귀하지 않는다.
- 수직 물리 하강과 카메라 추적은 유지할 수 있다. 게임 내 재시작·관전·자동 복귀를 제공하지 않는다.
- 읽기 전용 `PlayerMovement.IsEliminated`는 생존 false, 탈락 true이며 리셋 API는 없다.

## 화면 안내

- 생존 시 탈락 패널은 숨긴다.
- 탈락 판정 후 다음 GUI 표시 시점에 화면 중앙에 고대비 배경과 `ELIMINATED`를 표시한다. 정상 플레이에서 판정 후 1초 이내 표시해야 한다.
- 플레이어가 카메라 밖이거나 지형을 벗어나도 안내를 유지한다. 월드 오브젝트 위의 이름표나 Console 로그만으로 대체하지 않는다.
- 16:9 및 4:3 Game 뷰에서 중앙 배치·화면 내 문구·읽을 수 있는 크기와 대비를 확인한다. 카메라 렌더만으로 OnGUI 표시를 검증했다고 간주하지 않고 실제 Game 뷰를 확인한다.
- 버튼이나 재시작 안내는 표시하지 않는다. 영문 기본 문구를 사용해 추가 한글 폰트 자산을 요구하지 않는다.

## 경계·회귀 검증의 원칙

- 정확한 동일 높이 시험에서는 물리 중력 적분 전 판정을 검사한다. 적분 후 아래로 떨어진 상태를 동일 높이로 오인하지 않는다.
- 단위형 수동 틱 시험과 실제 SampleScene 자연 수명주기 시험을 모두 수행한다.
- 이미 탈락한 테스트 인스턴스를 순간 이동시켜 정상 점프·착지를 기대하지 않는다. 새 인스턴스로 시험을 격리한다.
- 기존 물리·입력 설정 및 가상 장치는 테스트 종료 시 복원한다.
