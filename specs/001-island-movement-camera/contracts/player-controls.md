# Player Controls Contract

**Date**: 2026-10-29
**Applies to**: 구현 완료 후 `Assets/Scenes/SampleScene.unity`

외부 HTTP/API는 없다. 이 문서는 플레이어 키보드 입력과 프로토타입 작성자의 Inspector 조작을 정의한다.

## 키보드 이동

| 입력 | 결과 |
|---|---|
| W / A / S / D | 화면 위 / 왼쪽 / 아래 / 오른쪽 방향의 지상 이동 |
| 이웃한 두 방향 | 대각선 이동, 입력 개수 때문에 더 빨라지지 않음 |
| W+S 또는 A+D | 해당 축 상쇄, 다른 축의 입력은 유지 |
| 네 키 모두 | 이동 입력 상쇄, 설정한 감속에 따라 정지 |
| 이동 키 해제 | 설정한 감속에 따라 정지 |

씬의 `PlayerInput`에 연결된 `Assets/Player_Actions.inputactions`의 `Player/Move` Vector2 액션과 `OnMove(InputValue)` 수신을 유지한다. 공용 `InputSystem_Actions.inputactions`와 혼동하지 않는다. 액션 이름/전달 방식을 바꾸는 경우 씬 PlayerInput과 자동 테스트도 함께 바꿔야 한다.

## 초점과 수명주기

- 다른 창으로 전환하거나 입력 컴포넌트를 끄면 캐시 이동 입력을 비우고 수평 이동을 멈춘다. Y 속도는 강제로 0으로 만들지 않는다.
- 복귀 때 눌린 키가 유지되고 있으면 자동으로 걷지 않는다. 이동 키를 모두 놓은 뒤 새로 눌러야 다시 움직인다.
- Play를 다시 시작하면 저장된 안전한 시작 위치에서 시작한다.

## 카메라

- 카메라는 캐릭터만 따라가며 몸 전체와 인접한 섬 표면을 보여준다.
- 캐릭터 이동·정지 중 커서를 어느 쪽으로 옮겨도 카메라 위치·방향·확대 정도에 영향을 주지 않는다.
- 같은 WASD 키는 같은 화면 방향에 대응한다. 입력에 따른 카메라 회전이나 수동 확대 조작은 없다.

## Inspector 조정

이동 속도·가속·감속·방향 전환, 카메라 각도·거리·FOV·추적 반응은 [data-model.md](../data-model.md)의 값으로 조정한다. 서로 다른 값으로 플레이해 효과를 비교할 수 있어야 하며 전용 설정 화면은 요구하지 않는다. 선택한 값은 Edit Mode에서 씬에 저장한다.

## 섬 경계와 제외 범위

섬 끝에 숨은 벽·위치 제한·자동 복귀를 넣지 않는다. 경계를 넘은 뒤의 점프·글라이딩·낙사 판정·리스폰은 이번 사용자 계약에 없다. 계속 시험하려면 Play를 종료하고 다시 시작한다. 온라인 대전·공격·커서 조준도 구현 범위 밖이다.
